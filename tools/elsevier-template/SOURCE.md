## Relevant Elsevier / Neural Networks instructions

- Elsevier LaTeX instructions endorse the **elsarticle** package for journal manuscript preparation and Editorial Manager submission.
- Neural Networks *Guide for Authors* (ScienceDirect): encourages use of Elsevier’s LaTeX template; does **not** mandate a journal-specific class other than the standard Elsevier LaTeX pathway.
- Neural Networks reference style: **APA 7th / author–year** (alphabetical reference list) → use `elsarticle` with `authoryear` and `elsarticle-harv.bst`.
- Highlights: **encouraged** (3–5 bullets, ≤85 characters each), separate editable file with “highlights” in the filename.
- Abstract: required, ≤250 words; keywords: 1–6 required.
- CRediT author contributions: required for corresponding authors.
- Competing interests / funding / research data statements: required per GFA.
