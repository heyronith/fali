\section{Standard Owen attribution and intervention identities}

FALI uses five binary factors $N=\{T,R,O,V,C\}$ and the prospectively fixed
coalition partition
\[
\Pi=\{\mathrm{SCORE}=\{T,R,O\},\mathrm{VALUE}=\{V\},\mathrm{CONTEXT}=\{C\}\}.
\]
Each coalition $K\subseteq N$ indexes the hybrid state in which members of $K$
take their perturbed-state values and all remaining factors take their intact-state
values. The characteristic function is $v(K)=U(\mathbf{1}_K)$, where utility is the
candidate-present task metric minus the candidate-zero task metric in the same
surrounding context.

The standard Owen value averages marginal contributions over all permutations
that keep members of each block contiguous. For the partition above there are
$3!\times 3!=36$ admissible permutations. Efficiency gives
\[
\phi_T+\phi_R+\phi_O+\phi_V+\phi_C
=v(N)-v(\varnothing)
=\Delta_h.
\]
The quotient game on SCORE/VALUE/CONTEXT satisfies
\[
\Phi_{\mathrm{SCORE}}=\phi_T+\phi_R+\phi_O.
\]
These identities allocate interaction under the specified counterfactual game.
They do not identify unique natural pathways.

\section{Method-validation chronology and controlled ground truth}

The attribution implementation was validated before substantive pretrained-model
experiments. An initial fixed-block-order implementation was rejected because it
was not the standard Owen value; EF-0R restored all 36 admissible permutations and
ordinary Shapley attribution on the quotient game. A subsequent implementation
review identified a batch-shared target partition and insufficiently independent
endpoint checks in EF-1; EF-1R introduced per-example batched partitions and
independent direct endpoint validation before pretrained-model experiments began.
The superseded implementations are retained only for audit history.

\subsection{Random-transformer implementation invariants}

The random TransformerLens validation model used two layers, two heads per layer,
$d_{\mathrm{model}}=32$, $d_{\mathrm{head}}=16$, $d_{\mathrm{mlp}}=64$,
context length 8, vocabulary size 48, FP32 CPU execution, and seed 4242.
The primary and candidate were L0H0 and L1H0.

Independent ordinary forwards gave
\[
E_A=0.4550457001,\qquad
E_B=-0.0856835023,\qquad
\Delta_h=-0.5407292023.
\]
The all-intact and all-perturbed FALI endpoint cells reproduced these quantities
with zero recorded discrepancy. Score-to-pattern reconstruction,
pattern/value-to-$z$ reconstruction, masked probability, candidate-output
injection, non-candidate isolation, Q/V/Q+V live-leak checks, and quotient-game
reconciliation all had zero recorded discrepancy at the reported precision.

\section{GPT-2 IOI confirmation}

\subsection{Design and prospectively frozen fine-channel hypotheses}

The canonical cohort used GPT-2 Small, the primary Name Movers L9H6, L9H9, and
L10H0 as the perturbed set, candidates L10H2 and L10H10, and architectural controls
L9H7 and L9H0. The design contained 15 low-level templates crossed with BABA/ABBA
structure, 30 prompts per stratum, and seeds 42, 1, 8, and 22, for 3600 prompts.

The EF-4 confirmation plan was committed before canonical fine-channel execution
and was recorded in the run configurations. The four primary directional hypotheses
were
\[
\phi_T>0,\ \phi_R<0
\]
for both L10H2 and L10H10. $\phi_O$ was descriptive. Point estimates equally
weighted 30 strata within each seed and then weighted the four seeds equally.
Confidence intervals used 10,000 hierarchical template-cluster bootstrap draws.
The confirmation additionally required all-seed directional agreement, broad
stratum support, and a template-0-excluded sensitivity.

\section{Pythia-160M induction transfer}

\subsection{Prospective design}

EF-6 was the one authorized cross-setting transfer test. Discovery used seed 42
only and was prohibited from inspecting FALI attributions. The frozen selection rule
chose L5H0 as the primary and L8H2 as the candidate. Confirmation used seeds 1,
8, and 22 with offsets 8, 16, and 24 and 128 examples per offset per seed.
The task metric was target-token natural-log probability. The transfer hypotheses
predicted $\phi_T>0$ and $\phi_R<0$.

The repeated-token construction used base length 32, target token $x_{j+1}$,
final query $q=32+j$, and target key $k=j+1$. The control replaced the first
32-token block with a disjoint token block. Estimates weighted offsets equally within
seed and seeds equally; confidence intervals used 10,000 deterministic bootstrap draws
within seed--offset cells.

\item \texttt{results/extended\_fali/ef6\_pythia\_induction/aggregate/}
\item \texttt{results/revision\_phase4/full/aggregate/}
\end{itemize}

No additional model, task, threshold, or replacement pair was introduced after the
reported EF-5 or EF-6 failures. Hybrid-state results should be interpreted as outcomes
of the stated counterfactual intervention game; the surrounding context factor remains
coarse and can aggregate multiple external computations.
