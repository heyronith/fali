\section{Introduction}\label{sec:introduction}

A component's causal importance in a transformer need not be stable under intervention. Removing one component can change the contribution of others: downstream layers can compensate for ablated computation, individual attention heads can change functional role depending on which other heads are available, and components that appear unimportant in the intact model can become important after a primary circuit is removed \citep{mcgrath2023hydra,mcdougall2023copysuppression,rushing2024selfrepair,nam2025causalhead,gong2026coax}. This conditionality is not merely a complication of terminology. Conditional co-ablation can recover backup components that first-order ablation scores miss, while causal-mediation analyses of activation patching show that a component's measured effect can contain substantial interactions with the state of the rest of the model \citep{gong2026coax,vaidyanathan2026curse}.

These results sharpen a question that localization alone does not answer. Suppose an attention head is known to become more or less useful after another circuit component is perturbed. \emph{What changed in and around that head that accounts for the shift in its causal usefulness?} A changed ablation effect does not distinguish among several possibilities. The head may route attention differently, the information carried by its value vectors may change, or an otherwise similar head output may become more or less useful because the surrounding network has changed. Even within changed routing, a task-relevant attention edge can strengthen because its own score increases, because rival scores decrease, or because score changes elsewhere alter the head's computation. Existing work provides important pieces of this picture---including conditional importance, interaction-aware attribution, and causal separation of query--key routing from value-mediated computation---but these pieces target different estimands \citep{gong2026coax,vaidyanathan2026curse,wang2026fewshot}.

We introduce \textbf{FALI (Factorized Attention-Level Intervention)}, a hypothesis-driven framework for resolving such conditional changes in a selected attention head. FALI begins with two model states: an intact state $A$ and a perturbed state $B$. For a candidate head whose task-relevant target edge or edge set has already been specified, FALI factorizes the cross-state change into five intervention variables: target scores $T$, rival scores $R$, other structurally valid attention scores $O$, value content $V$, and surrounding-network context $C$. The first three factors jointly determine the candidate's attention pattern; $V$ determines the content available to be transported; and $C$ switches the surrounding computation between the intact and perturbed model states. For each of the $2^5$ hybrid states, FALI defines the candidate's utility as its output-grounded contribution to the task metric: the metric with the hybrid candidate output injected minus the metric with that candidate zeroed in the same surrounding context. Thus the object being explained is not an attention probability, but the candidate head's change in causal usefulness.

Interactions among these factors make a purely sequential attribution arbitrary. We therefore use the standard Owen value with the prospectively fixed coalition structure $\{\mathrm{SCORE}=\{T,R,O\},\mathrm{VALUE}=\{V\},\mathrm{CONTEXT}=\{C\}\}$ \citep{owen1977values}. This gives a fine decomposition into $\phi_T,\phi_R,\phi_O,\phi_V,\phi_C$ while preserving a coarse score/value/context decomposition: $\phi_T+\phi_R+\phi_O$ equals the SCORE contribution in the quotient game. We make no claim of mathematical novelty for the Owen value. The methodological object is the counterfactual intervention game and the architecture-aligned factorization to which it is applied.

FALI is deliberately downstream of circuit discovery. Path and activation patching localize components or paths that affect behavior \citep{goldowskydill2023pathpatching,zhang2024activationpatching,heimersheim2024activationpatching}; conditional methods such as CoAx ask which components become important after a primary set is removed \citep{gong2026coax}; interaction analyses establish that measured causal effects can depend on the rest of the network \citep{vaidyanathan2026curse}. FALI instead takes a selected conditional change as its explanandum and asks which changes in the candidate's score computation, value content, or surrounding context account for it under an explicit intervention model. To our knowledge, FALI is the first framework to decompose the intervention-induced change in an attention head's output-grounded causal usefulness into architecture-aligned score, value, and surrounding-context contributions while resolving the score contribution into target, rival, and other-score channels. This claim is narrower than separating routing from value content itself, which is established in transformer-circuit analyses and recent causal decompositions \citep{elhage2021mathematical,franco2025attentioncausal,wang2026fewshot}.

We validate the intervention semantics before using FALI on pretrained models. Deterministic synthetic attention systems isolate each of $T,R,O,V,C$ in turn and test a known cross-factor interaction; a small randomly initialized transformer then checks score-to-pattern reconstruction, value-to-head-output reconstruction, endpoint identities, batch-specific score partitions, absence of live-candidate leakage, and agreement between the fine Owen decomposition and its coarse quotient game. These tests are intended to establish that the implemented decomposition identifies the factor manipulated in controlled systems, not that the chosen factorization is the unique natural decomposition of transformer computation.

We then study two substantively different settings. In GPT-2 Small on indirect object identification (IOI) \citep{wang2023ioi}, corrected functional analysis first shows why attention adaptation cannot be used as a proxy for recruitment: L10H2 becomes more causally useful after the canonical primary Name Movers are removed, whereas L10H10 increases target attention strongly while its total causal usefulness decreases. On broad canonical IOI templates, FALI assigns L10H2 a positive target-score contribution and a negative rival-score contribution; the same target-positive/rival-negative fine-score pattern also appears for L10H10 despite its negative total conditional gain. Tested matched-mean and matched-resample intervention variants preserve the preregistered fine-channel result, while a broader preregistered robustness gate fails because its zero-damage reference criterion is not satisfied; we report both outcomes.

Finally, we test a preregistered transfer of the GPT-2 fine-score mechanism to a different model family and task: Pythia-160M induction, using an established induction setting \citep{olsson2022induction}. Conditional recruitment appears again, but the fine-score signs reverse: the target contribution is negative and the rival contribution positive. The transfer hypothesis therefore fails. Across the two studied settings, conditional recruitment is shared while the preregistered fine-score mechanism is not. This negative transfer result is central to the paper: it demonstrates the value of distinguishing a common functional label from the mechanism that produces it, rather than treating recruitment itself as evidence for a single internal explanation.

Our contributions are threefold:
\begin{enumerate}
    \item We define an output-grounded counterfactual intervention game for explaining the cross-state change in a selected attention head's causal usefulness.
    \item We factor that change into score, value, and surrounding-context contributions, with target/rival/other-score resolution inside SCORE and coarse--fine consistency via standard Owen attribution.
    \item We show that the same high-level conditional-recruitment phenomenon can conceal different fine mechanisms: GPT-2 IOI and Pythia induction exhibit opposite target/rival score signs under the specified FALI games.
\end{enumerate}

\section{Related Work}\label{sec:related}

\subsection{Self-repair and conditional component importance}\label{sec:rw-conditional}

Transformer circuits can adapt when components are ablated. The IOI circuit analysis of \citet{wang2023ioi} identified primary and backup Name Mover heads in GPT-2 Small, providing an early concrete setting in which several attention heads participate in a behavior and some become especially relevant under intervention. Subsequent work established self-repair more broadly. The Hydra effect describes compensatory changes in downstream language-model computation after ablation \citep{mcgrath2023hydra}. Copy-suppression analysis showed that self-repair can arise through specific functional mechanisms rather than a single generic backup process \citep{mcdougall2023copysuppression}. \citet{rushing2024selfrepair} further found self-repair across model families and the full training distribution, with substantial prompt-level variability and contributions from mechanisms including LayerNorm scaling and anti-erasure.

FALI does not claim the discovery of self-repair or heterogeneous compensation. More directly, it also does not introduce the idea of conditional component importance. \citet{gong2026coax} formalize Conditional Co-Ablation (CoAx), which scores how much a remaining unit's ablation effect grows once a primary set has been removed. Their experiments show that this conditional score can recover backup heads missed by first-order rankings and transfers from GPT-2 IOI to induction settings across multiple models. This establishes both the empirical relevance and the practical utility of asking how component importance changes under intervention.

The distinction is therefore one of explanatory stage. Conditional ablation answers whether, or to what extent, a component becomes more important in a perturbed circuit. FALI assumes such a candidate has already been selected and asks which changes in the candidate's attention-score computation, value content, and surrounding context account for that cross-state change. In this sense CoAx and FALI are complementary: the former can identify \emph{which} components warrant conditional analysis, whereas FALI provides a structured mechanism-resolution experiment for a chosen attention head.

\subsection{Interaction-aware causal attribution}\label{sec:rw-interaction}

Activation patching and related interchange interventions are standard tools for testing whether internal activations causally contribute to model behavior. Path patching refines this idea to hypotheses about particular computational paths \citep{goldowskydill2023pathpatching}; systematic studies have also shown that patching conclusions depend on choices such as corruption, metric, and intervention design \citep{zhang2024activationpatching,heimersheim2024activationpatching}. These methods are primarily localization or causal-testing tools: they identify components, activations, or paths whose replacement changes an outcome. FALI uses the same broad experimental tradition but addresses a different estimand---the change in one selected head's output-grounded causal contribution between two circuit states.

A particularly close conceptual neighbor is \citet{vaidyanathan2026curse}. Re-deriving activation patching through causal mediation analysis, they show that a component's natural indirect effect can include interaction terms that measure how its effect depends on the state of other model components. In GPT-2 IOI these interactions can hide conditionally important components, inflate others, and contribute to instability in component rankings. This result rules out any novelty claim that FALI is the first method to observe context-dependent causal effects. Instead, it motivates the next question: once a conditional or interaction-dependent effect has been identified, can we resolve that change into architecture-level factors of the selected attention head?

Causal Head Gating provides a complementary head-level perspective. \citet{nam2025causalhead} learn gates over attention heads, classify their roles as facilitating, interfering, or irrelevant, and find that head roles can depend on interactions with other heads. FALI is neither a learned gating method nor a global head-role taxonomy. It fixes one candidate head and two model states, then intervenes on explicitly defined internal factors of that head and the surrounding model. Likewise, we do not claim that FALI is generally more faithful than patching: intervention-based interpretability results can be sensitive to methodology, as demonstrated by circuit-faithfulness studies \citep{miller2024faithfulness}. Our robustness experiments therefore support only the intervention variants actually tested.

These interaction-aware results also inform our interpretation of the context factor $C$. Under FALI, $C$ is not a localized ``downstream sensitivity'' variable. It denotes the surrounding model computation that differs between intact and perturbed contexts outside the explicitly injected candidate score/value state. It can therefore aggregate changes in other heads, MLPs, residual representations, normalization, and upstream or downstream computation. A large $\phi_C$ is evidence about the specified counterfactual game, not identification of a unique external mechanism.

\subsection{Decomposing attention computation}\label{sec:rw-attention}

The separation between attention routing and transported content is foundational rather than novel to FALI. The transformer-circuits framework distinguishes the query--key (QK) circuit, which determines attention scores and patterns, from the output/value (OV) circuit, which determines what information is written when a source position is attended to \citep{elhage2021mathematical}. Later causal work makes increasingly fine distinctions inside attention computation. \citet{franco2025attentioncausal} identify low-dimensional communication signals with a causal relationship to attention patterns, while \citet{wang2026fewshot} causally separate Query--Key routing from Value updates when explaining how few-shot examples shape function vectors. Recent factorial intervention work likewise shows that attention allocation and token content can be experimentally separated yet strongly coupled in a different robustness setting \citep{zhu2026lexical}.

FALI builds on these distinctions but changes the object being decomposed. Its dependent quantity is not the attention pattern itself, nor the quality of a function vector, but the \emph{cross-state change in the selected head's downstream causal usefulness}. SCORE and VALUE are therefore accompanied by an explicit CONTEXT factor. Within SCORE, FALI further partitions structurally valid score coordinates into task-target scores $T$, rival scores $R$ in the same task-relevant query row, and all other valid scores $O$. This target/rival/other partition is hypothesis-driven: it requires a task-relevant target edge or edge set to be specified in advance, and is not an automatic circuit-discovery procedure.

Because score, value, and context can interact non-additively, FALI uses the standard Owen value for a game with a priori coalition structure \citep{owen1977values}. The coalition structure is fixed as SCORE=$\{T,R,O\}$, VALUE=$\{V\}$, and CONTEXT=$\{C\}$. Owen attribution is established game-theoretic machinery; our use of it is motivated by the requirement that the fine score contributions reconcile with the coarse SCORE contribution rather than by a claim of a new attribution theorem. The resulting values should also be read relative to the intervention semantics. Hybrid internal states need not be states the unmodified model would naturally visit, and causal-intervention research has documented that representation-level interventions can move models away from their natural internal distributions \citep{grant2025divergent}. We therefore treat FALI as a controlled counterfactual decomposition, not as evidence that the model implements five independent natural pathways.

Finally, our emphasis on explicit validation reflects a broader evaluation problem in mechanistic interpretability. Benchmarks such as MIB prioritize precise recovery of causal pathways or variables rather than plausible narrative alone \citep{mueller2025mib}. FALI's synthetic single-factor systems and implementation invariants serve the narrower purpose of checking that the intervention pipeline recovers known manipulated factors before empirical use. They do not remove the substantive limitations of target selection, coalition choice, or intervention dependence, which we address explicitly in Section~\ref{sec:limitations}.
