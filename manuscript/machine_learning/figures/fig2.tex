\caption{\textbf{FALI constructs an output-grounded 32-cell intervention game.}
First, structurally valid candidate-head scores are partitioned into task-target coordinates $T$, rivals $R$ in the same query row, and all other valid scores $O$.
Second, each hybrid chooses intact or perturbed sources independently for $T,R,O,V,$ and $C$, reconstructs the candidate attention pattern and head output, and defines utility relative to a candidate-zero run in the same context.
Third, all $2^5=32$ hybrid states are evaluated and attributed with the standard Owen value under $\mathrm{SCORE}=\{T,R,O\}$, $\mathrm{VALUE}=\{V\}$, and $\mathrm{CONTEXT}=\{C\}$.
The fine attributions sum to $\Delta_h$, and $\phi_T+\phi_R+\phi_O$ equals the coarse SCORE contribution.
Hybrid cells are controlled counterfactual states rather than claims about unique natural pathways.}
