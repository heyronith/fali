\section{Related Work}\label{sec:related}

\subsection{Self-repair and conditional importance}\label{sec:rw-conditional}

Mechanistic studies increasingly show that component importance is conditional on the state of the surrounding circuit. In GPT-2 IOI, primary and backup Name Mover heads provide a concrete setting in which multiple attention heads support the same behavior \citep{wang2023ioi}. Subsequent work on the Hydra effect, copy suppression, and broader self-repair established that ablations can induce compensatory changes through multiple mechanisms rather than a single generic backup process \citep{mcgrath2023hydra,mcdougall2023copysuppression,rushing2024selfrepair}. Prompt-specific circuit analysis further cautions that even within a named task, mechanisms can vary across prompt families and model families \citep{franco2026promptspecific}.

FALI does not introduce self-repair or conditional importance. The closest operational precursor is Conditional Co-Ablation (CoAx), which measures how much a component's ablation effect changes after a primary set is removed and can recover backup components missed by first-order rankings \citep{gong2026coax}. The distinction is one of explanatory stage: conditional ablation identifies \emph{which} components become more important, whereas FALI takes a selected change in importance as the object to be explained.

\subsection{Interaction-aware causal attribution}\label{sec:rw-interaction}

Activation patching and path patching test whether internal activations or paths causally influence behavior, but their conclusions depend on intervention choices and the state of the surrounding model \citep{goldowskydill2023pathpatching,zhang2024activationpatching,heimersheim2024activationpatching}. A particularly close conceptual neighbor is the causal-mediation analysis of \citet{vaidyanathan2026curse}, which shows that component effects can contain substantial interactions with the rest of the network. This rules out any claim that FALI is the first method to reveal context-dependent causal effects. FALI instead asks how a selected interaction-dependent change can be resolved into architecture-aligned factors of an attention head.

Related head-level work likewise finds that attention-head roles can depend on interactions with other heads \citep{nam2025causalhead}. FALI is not a global head-role taxonomy or a learned gating method. It fixes one candidate head, two circuit states, and an explicit intervention algebra. Its context factor $C$ therefore denotes the surrounding computation not explicitly supplied by the candidate score/value state; it can aggregate changes in other heads, MLPs, residual representations, normalization, and upstream or downstream computation. A large $\phi_C$ should not be read as localization of a unique external pathway.

\subsection{Decomposing attention computation}\label{sec:rw-attention}

Separating attention routing from transported content is established rather than novel. Transformer-circuit analyses distinguish query--key (QK) computation from output/value (OV) computation, and later causal work further separates routing from value-mediated information flow \citep{elhage2021mathematical,franco2025attentioncausal,wang2026fewshot}. Factorial intervention studies also show that attention allocation and token content can be manipulated separately while remaining strongly coupled \citep{zhu2026lexical}.

FALI changes the quantity being decomposed. Its dependent variable is the \emph{cross-state change in a selected head's output-grounded causal usefulness}, not an attention pattern or representation alone. SCORE and VALUE are therefore accompanied by an explicit CONTEXT factor; SCORE is further resolved into target, rival, and other valid score coordinates. Because these factors interact, we use the standard Owen value with the coalition structure SCORE=$\{T,R,O\}$, VALUE=$\{V\}$, CONTEXT=$\{C\}$ \citep{owen1977values}. The mathematics is established; the contribution is the intervention game and the architecture-aligned estimand to which it is applied.

Hybrid internal states may be off the model's natural activation manifold, so the resulting attributions are best interpreted as controlled counterfactual explanations under specified intervention semantics, not as evidence that the model implements five independent natural pathways \citep{grant2025divergent}. This emphasis on explicit intervention validation is consistent with broader efforts to evaluate mechanistic explanations against causal ground truth rather than narrative plausibility alone \citep{mueller2025mib}.

An earlier public preprint used the name FALI for \emph{Frozen Attention Logit Intervention}, a two-factor target-versus-background decomposition of attention-probability changes in GPT-2 IOI \citep{sharmila2026attentionrepairs}. The present work supersedes that interpretation. It changes the estimand to output-grounded causal usefulness, expands the game to $T/R/O/V/C$, introduces coarse--fine reconciliation through standard Owen attribution, validates the intervention semantics in controlled systems, and tests a prospectively specified cross-setting mechanism transfer. The historical two-factor formulation is retained only as a nested special case.
