# Historical FALI archive (minimal)

This directory retains **provenance only** for material superseded by the current
**Factorized Attention-Level Intervention** paper (`manuscript/neural_networks/`).

## Frozen Attention Logit Intervention

The name FALI originally referred to an attention-probability / frozen-logit
intervention analysis (see `paper_frozen_attention.tex` and scripts under
`experiments/`). The current paper changes the estimand to output-grounded
conditional causal usefulness with a $T/R/O/V/C$ Owen game and treats the earlier
method as a nested special case (Related Work).

## Policy

- One authoritative historical copy is enough.
- Do not treat these files as current scientific evidence.
- Failed EF-5 / EF-6 Factorized results remain under `results/extended_fali/` (not here).

## Raw Frozen-era dumps

Canonical local paths remain under `results/raw/` (often gitignored; see
`results/RAW_DATA_INDEX.json`). Optional local copies may exist under
`archive/historical_fali/raw/` for offline provenance; they are not required in Git.
